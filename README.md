# ShopMetrics – E-Commerce Funnel and Basket Analytics

## Project Overview
ShopMetrics is a data analytics project designed to analyze e-commerce customer behavior, sales performance, product performance, and shopping funnel conversion. It helps identify customer drop-offs and understand business performance through an interactive dashboard.

## Objectives
- Analyze customer shopping behavior.
- Calculate important business KPIs.
- Analyze sales and product category performance.
- Identify shopping funnel drop-offs.
- Visualize insights using an interactive dashboard.

## Technologies Used
- Python
- Pandas
- MySQL
- SQL
- Streamlit
- Plotly

## Project Structure
- `analytics/` – Python scripts for data generation, cleaning, analysis, and dashboard.
- `data/raw/` – Raw datasets.
- `data/processed/` – Cleaned datasets and analysis results.
- `database/` – SQL schema, seed data, and queries.

## Dashboard Features
- Interactive light and dark themes.
- Product category filter.
- Key performance indicator cards.
